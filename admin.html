Conectate a tu repositorio de GitHub

Esta página edita directamente data/productos.json en tu repositorio de GitHub (donde está publicado el sitio) usando la API de GitHub. Necesitás un Personal Access Token con permiso de lectura y escritura sobre "Contents" de ESE repositorio únicamente.

El token se guarda solo en este navegador (nunca se envía a ningún otro lado). Usá esta página solo en dispositivos de confianza, y si sospechás que se filtró, revocalo desde GitHub.

Datos de contacto del sitio

Podés cargar varios números de WhatsApp (por ejemplo Ventas y Soporte). Todos aparecen siempre como opciones de contacto: en la sección Contacto del sitio se listan todos, y en los botones rápidos (nav, hero, "Consultar" de cada producto) — si hay más de uno cargado — se le muestra al visitante un selector para que elija con quién quiere hablar. No hay ningún número "predeterminado". Después de agregar, editar o borrar un número, acordate de tocar "Guardar datos de contacto" para que quede publicado.
